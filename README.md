# آزمایشگاه ستاپ اسپایک

Written by Ali Edrisi

ابزار آزمایشی برای دیدن عملکرد استراتژی: شکست ساختار (BOS)، کندل اسپایک، ورود اول و دوم، حد ضرر و حد سود یک به یک.

- `index.html`: خود ابزار (یک فایل کامل). با صفحات گیت‌هاب باز می‌شود.
- `engine.js`: منطق استراتژی به صورت مجزا.
- `test.js`: آزمون منطق. اجرا: `node test.js`

برای روشن کردن صفحه: Settings > Pages > Branch: main / root
